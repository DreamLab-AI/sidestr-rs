# BIP 340, 341 and 86 vectors

The official BIP 340, BIP 341 and BIP 86 test vectors as the reference
engine vendors them: copied verbatim from `bitcoin-desktop/schema` at
`b8cbf6337c7450fe14ddc5bce00c7280059aab5d`, `test/vectors/bip340.json`,
`test/vectors/bip341.json` and `test/vectors/bip86.json`. They are the
vectors `siding/test/keys-test.mjs` (sidestr/spec `bd1d692`) runs, and
`tests/keys.rs` runs them against `sidestr_core::keys`.
